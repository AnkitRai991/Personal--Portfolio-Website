# Personal-Portfolio-Website

A modern, responsive personal portfolio built with HTML, CSS, and JavaScript — designed to showcase my projects, skills, experience, and contact details in an elegant, organized, and user-friendly way.

## 🌟 Features

- ✅ Responsive design works across desktop, tablet & mobile  
- 🛠️ Clean, minimal layout for easy navigation  
- 📁 Sections for About Me, Projects / Portfolio, Skills, Contact, and links to social profiles  
- 🎨 Easy to customize — swap images, update content, add new projects  
- 📷 Visual showcase with images/screenshots of projects  

## 🧰 Built With / Tech Stack

- HTML  
- CSS  
- JavaScript
